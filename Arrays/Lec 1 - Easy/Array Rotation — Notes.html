Array Rotation

Shifting elements left or right by k positions — from the naive one-step-at-a-time approach to the O(n) three-reversal trick, plus its connection to rotating a linked list.

Right rotation, k = 2[1, 2, 3, 4, 5] → [4, 5, 1, 2, 3]
Left rotation, k = 2[1, 2, 3, 4, 5] → [3, 4, 5, 1, 2]

01 Left rotation by one position

The first element moves to the end. Store it, shift everything else one step left, then drop it back in at the last index.

static int[] rotateArrayLeft(int[] arr, int n)
{
    int temp = arr[0];
    for (int i = 0; i < n - 1; i++)
        arr[i] = arr[i + 1];
    arr[n - 1] = temp;
    return arr;
}
[1, 2, 3, 4, 5] → temp = 1 shift: [2, 3, 4, 5, 5] place temp: [2, 3, 4, 5, 1]

Time O(n)  ·  Space O(1)

02 Left rotation, k times

Just repeat the single-step rotation k times.

static int[] rotateArrayLeftKTimes(int[] arr, int n, int k)
{
    while (k > 0)
    {
        int temp = arr[0];
        for (int i = 0; i < n - 1; i++)
            arr[i] = arr[i + 1];
        arr[n - 1] = temp;
        k--;
    }
    return arr;
}

For [1,2,3,4,5] with k=2: first pass → [2,3,4,5,1], second pass → [3,4,5,1,2].

Time O(n × k)  ·  Space O(1)

03 Right rotation by one position

The last element moves to the front. Store it, shift everything else one step right, then place it at index 0.

static int[] rotateArrayRight(int[] arr, int n)
{
    int temp = arr[n - 1];
    for (int i = n - 1; i > 0; i--)
        arr[i] = arr[i - 1];
    arr[0] = temp;
    return arr;
}
[1, 2, 3, 4, 5] → temp = 5 shift right→left: [1, 1, 2, 3, 4] place temp: [5, 1, 2, 3, 4]
Why shift right-to-left? Starting from the end and moving backward avoids overwriting values you still need. Going left-to-right would clobber data before it's copied.

04 Right rotation, k times

static int[] rotateArrayRightKtimes(int[] arr, int n, int k)
{
    while (k > 0)
    {
        int temp = arr[n - 1];
        for (int i = n - 1; i > 0; i--)
            arr[i] = arr[i - 1];
        arr[0] = temp;
        k--;
    }
    return arr;
}

Time O(n × k)  ·  Space O(1) — correct, but slow when k is large.

05 The optimized trick: rotate by reversing

Rather than shifting one element at a time, three well-placed reversals rotate the whole array in a single O(n) pass. Everything below builds on one helper:

void reverseArray(int[] nums, int start, int end)
{
    while (start < end)
    {
        int temp = nums[start];
        nums[start] = nums[end];
        nums[end] = temp;
        start++;
        end--;
    }
}

How it works

Two pointers close in from both ends, swapping as they go.

[1, 2, 3, 4, 5] reverseArray(nums, 0, 4) start↓ ↓end [1, 2, 3, 4, 5] → swap → [5, 2, 3, 4, 1] start↓ ↓end [5, 2, 3, 4, 1] → swap → [5, 4, 3, 2, 1]

Time O(n)  ·  Space O(1)

06 Right rotation via three reversals

reverseArray(nums, 0, n - 1);
reverseArray(nums, 0, k - 1);
reverseArray(nums, k, n - 1);

Split [1,2,3,4,5] (k=2) into two mental blocks — [1,2,3] and [4,5] — and swap their order:

Reverse ALL: [1,2,3,4,5] → [5,4,3,2,1] Reverse first k: [5,4 | 3,2,1] → [4,5 | 3,2,1] Reverse rest: [4,5 | 3,2,1] → [4,5 | 1,2,3]
RIGHT ROTATION
Reverse ALL → Reverse FIRST k → Reverse REST

07 Left rotation via three reversals

reverseArray(nums, 0, k - 1);
reverseArray(nums, k, n - 1);
reverseArray(nums, 0, n - 1);

The blocks reverse in the opposite order from the right rotation:

Reverse first k: [1,2 | 3,4,5] → [2,1 | 3,4,5] Reverse rest: [2,1 | 3,4,5] → [2,1 | 5,4,3] Reverse ALL: [2,1,5,4,3] → [3,4,5,1,2]
LEFT ROTATION
Reverse FIRST k → Reverse REST → Reverse ALL

08 Why k = k % n

Rotating an array of length n by n steps brings it back to where it started, so any k larger than n has a smaller equivalent rotation. For n=5, rotating by 12 is the same as rotating by 12 % 5 = 2. This matters most for the reverse method, since an out-of-range k would break the slice indices.

09 Putting it together

public int[] rotateArray(int[] nums, int k, String direction)
{
    int n = nums.length;
    if (n == 0 || k == 0) return nums;
    k = k % n;

    if (direction.equals("right"))
    {
        reverseArray(nums, 0, n - 1);
        reverseArray(nums, 0, k - 1);
        reverseArray(nums, k, n - 1);
    }
    else if (direction.equals("left"))
    {
        reverseArray(nums, 0, k - 1);
        reverseArray(nums, k, n - 1);
        reverseArray(nums, 0, n - 1);
    }
    return nums;
}

Decision checklist

  1. Which direction — left or right?
  2. Is k ≥ n? → normalize with k = k % n
  3. Use the reverse technique for O(n)
  4. Right → reverse ALL, then FIRST k, then REST
  5. Left → reverse FIRST k, then REST, then ALL

12 Core mental model

RIGHT A B C | D E ↓ D E | A B C
LEFT A B | C D E ↓ C D E | A B

Rotation is just moving one section of the array to the other side. Reversal is a clever, in-place way to do that move.
